## CLI & Tooling

### Homebrew

The missing package manager for macOS (and Linux) — community-maintained formulae for everyday CLI tools and apps.

[![View Repo](https://img.shields.io/badge/View-Repo-blue?style=flat&logo=github)](https://github.com/Homebrew/brew)

### PowerToys

Microsoft's open-source suite of Windows power-user utilities — FancyZones, PowerToys Run, Color Picker, and more.

[![View Repo](https://img.shields.io/badge/View-Repo-blue?style=flat&logo=github)](https://github.com/microsoft/PowerToys)

### rclone

"rsync for cloud storage" — sync, copy, and mount across 70+ cloud providers and protocols from the CLI.

[![View Repo](https://img.shields.io/badge/View-Repo-blue?style=flat&logo=github)](https://github.com/rclone/rclone)

### scrcpy

Display and control Android devices from a desktop via USB or TCP/IP — no root required, low latency.

[![View Repo](https://img.shields.io/badge/View-Repo-blue?style=flat&logo=github)](https://github.com/Genymobile/scrcpy)

### yadm

Dotfile manager built on top of git — track home-directory config across machines, with encryption and alt-files for per-host overrides.

[![View Repo](https://img.shields.io/badge/View-Repo-blue?style=flat&logo=github)](https://github.com/yadm-dev/yadm)

## Speech / ASR

### edge-tts

Python module that uses Microsoft Edge's online TTS service — high-quality neural voices without an API key.

[![View Repo](https://img.shields.io/badge/View-Repo-blue?style=flat&logo=github)](https://github.com/rany2/edge-tts)

### jiwer

Fast, minimal WER/CER computation for ASR evaluation — the de-facto Python library for transcription accuracy metrics.

[![View Repo](https://img.shields.io/badge/View-Repo-blue?style=flat&logo=github)](https://github.com/jitsi/jiwer)

### whisper.cpp

Plain C/C++ port of OpenAI's Whisper — runs local speech-to-text on CPU/GPU without Python.

[![View Repo](https://img.shields.io/badge/View-Repo-blue?style=flat&logo=github)](https://github.com/ggml-org/whisper.cpp)
